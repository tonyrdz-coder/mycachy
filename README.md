# mycachy

A minimal, keyboard-driven Hyprland desktop for CachyOS.

## Install

```bash
git clone https://github.com/tonyrdz-coder/mycachy.git
cd mycachy
./install.sh
```

Log out and back in after install.

## Stack

| Role | Tool |
|------|------|
| Compositor | Hyprland |
| Bar | Waybar |
| Launcher / Menus | Walker |
| Terminal | Foot |
| Notifications | Mako |
| File manager | Yazi |
| Bluetooth | bluetui |
| WiFi | impala |
| Audio | PipeWire + WirePlumber |
| Shell | Fish + Starship |
